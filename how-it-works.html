Rules

Rules and their justification

A rule is a fixed relationship:

  • IF a decision takes some value,
  • THEN an indicator changes,
  • BECAUSE of evidence or reasoning.

Effects are points added to the baseline of 50.

Interactions

When decisions depend on each other

An interaction changes an indicator only when two specific choices are made together. Each one uses a different pair of decisions.
